Welcome

This is the one-time setup wizard for your personal X bookmark digest.

  1. We'll fetch all your X bookmarks (up to the API's 800-bookmark cap).
  2. Claude will read them and propose a personalized taxonomy.
  3. You'll edit the proposal — rename, merge, split, delete, or add categories.
  4. Once you finalize the taxonomy, every bookmark gets classified.
  5. You'll review the classifications and correct any miscategorizations.
  6. From then on, you'll get a weekly Monday-morning digest.

This will use a small amount of X API and Anthropic API budget — typically under $5 of API spend total for setup.
